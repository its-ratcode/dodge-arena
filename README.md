# Dodge Game

A fast-paced top-down arena dodging game built with Python and pygame.

> Work in progress.

## Getting started

Requires Python 3.10+.

```bash
pip install -r requirements.txt
python -m app
```

## Controls

| Input | Action |
|---|---|
| Right-click | Walk to the clicked point |
| Hold right-click | Keep following the cursor |
| Esc | Quit |
